There are currently **no questions blocking the exact-front interaction prototype**.

- no unseen geometry or dimensions should be invented.

## Deferred input required for true 3D

A production-accurate 3D bottle cannot be created from the front view alone without inference. Before returning to a true GLB, provide at least one of:

1. measured bottle width × height × depth plus neck/cap dimensions;
2. straight side, top and back photographs with a scale reference;
3. CAD / GLB / FBX / OBJ from the bottle supplier;
4. a photogrammetry / 3D scan.

These are **not blockers** for the current exact-front rail prototype.
