# Reference Assets

## Amber Touch

The supplied WAVE Amber Touch bottle reference is stored in this repository as:

`amber-touch-reference.webp.b64`

It is a base64-encoded WebP reference image.

To decode it on macOS/Linux:

```bash
base64 -d assets/reference/amber-touch-reference.webp.b64 > assets/reference/amber-touch-reference.webp
```

If your system's `base64` command uses a different decode flag, use the equivalent option.

This reference is for product/visual development. Do not invent missing bottle details from memory; compare against the supplied source when fidelity matters.
